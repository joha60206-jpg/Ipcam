ipcam

Turns an Android phone into an IP camera (video, audio, snapshot, password).


Get the APK (no Android Studio needed)


Create a new GitHub repo and upload everything in this folder (keep the .github folder).

Open the Actions tab -> "Build APK" -> wait ~3 min.

Download the ipcam-apk artifact, unzip, install app-debug.apk on your phone.


Use

Start server, then open http://PHONE_IP:8080



/video MJPEG stream - /shot.jpg snapshot - /audio.wav audio
